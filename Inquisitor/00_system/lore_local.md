## §1. ТРИБУНАЛ

**Инквизиция в Трикастелле.** Постоянный орган, не разъездной.
**Занимается только религиозными делами.** Светские — магистрат, совет гильдий, светский суд.

**Задачи:**
- расследование (следователь);
- обвинение (прокурор);
- передача дела судьям;
- исполнение приговора — через палачей, не своими руками.

**Здание:** у городской стены, не в нищих кварталах. Большое, с двором, каменная ограда. Собственный **тайный ход** за городскую стену.
Внутри: покои Инквизитора, рабочие кабинеты, камеры для заключённых (разного вида), пыточная. **Самодостаточное.**

**Тюрьма:** своя, при трибунале. Прямой юридической связи с магистратской нет. Ситуативно возможна.

**Символика:**
- **Символ** — лезвие ножа, зажатое в кулак.
- **Применение** — печати, оттиск на сургуче, пряжка.
- **Пряжка** — внешний знак принадлежности. Элемент одежды или спрятана — по ситуации.
- **Металл** — серебро для значимых сотрудников; остальные — сопроводительное письмо с печатью. **У Инквизитора — золотая, только у него.**

**Пропуск:** пряжка или документ с печатью. **Функция:** не платить пошлины, не досматриваться, не задерживаться (в т.ч. на переправе Альдобранди).

## §2. СТРУКТУРА

**Инквизитор** — один. **Старший инквизитор.** Протагонист.
- Совмещает **прокурора** и **следователя**.
- Занимается только религиозными делами.
- Штат Странников, подчинённых ему.

**Штат** (формируется по сюжету):
- **секретарь** — личный Инквизитора, правая рука, знает почти всё, что и он;
- **тайная стража, шпионы, охранники, следователи** — разные люди и функции, возможно совмещение;
- **униформа:** нет. Либо одежда Странников (см. `mir/religiya/mir_religiya`), либо городская — по ситуации.

**Суд:**
- **Трое судей**, по одному от **каждого из трёх храмов**.
- **Старший** — жрец храма Гильдии Каменщиков. Он же — **старший жрец города** (выборная должность, утверждается Материн Голосом).
- **Младшие** — жрецы храмов Торговцев и Ростовщиков. Назначаются храмами, без обязательного утверждения от Матери.
- **Срок** — 5 лет, переизбираются.
- **Назначение:** совет жрецов храмов → утверждение от Материн Голоса (может отвергнуть или предложить своего).

**Палачи:**
- **Наёмные из Странников Матери.** Отдельная функция внутри ордена.
- Казни и физические наказания — их работа. **Не работа трибунала.**
- Виды и места казни — решение судей, туманно для сюжета.

**Вертикаль:**
Материн Голос (Монтевельо) → старший жрец города (он же — старший судья, храм Каменщиков) → Инквизитор.

## §3. КАК ВЕДЁТСЯ ДЕЛО

**Начало:**
- **донос** от жителя;
- **поручение/просьба** жрецов.

**Донос должен быть подтверждён:** свидетели или проверка инквизиции, если тема достаточно интересная.

**Процедура:**
1. Инквизитор расследует, собирает доказательства.
2. Передаёт дело судьям.
3. Судьи решают.
4. Приговор исполняют палачи (наёмные из Странников).

**Еретики** — прямая работа трибунала как следователя и обвинителя. Испытание (по религии) — отдельная процедура, конкретика в сюжете.

## §4. ПОЛНОМОЧИЯ

**Может:**
- войти в Академию при **основаниях** (отказ — тяжкое нарушение церковных законов);
- арестовать гражданина при основаниях;
- арестовать члена гильдии по религиозному делу;
- арестовать аристократа — с трением (семья будет противодействовать);
- вести расследование самостоятельно или по поручению жрецов;
- передать дело судьям;
- использовать палачей из Странников;
- **не платить пошлины** (пропуск);
- **не досматриваться** (грузы).

**Не может:**
- казнить сам — только через палачей;
- арестовывать по светским делам;
- игнорировать Божественный закон;
- действовать **без оснований** (иначе — отказ, жалоба, апелляция в Монтевельо).

**«Основание»** — подтверждённый донос или свидетельство.

---

## §5. ОТНОШЕНИЯ С ВЛАСТЬЮ

**Светская власть (магистрат Корси, совет гильдий):**
- Союз — нет. Формальное подчинение — нет.
- **Трение** при спорных юрисдикциях.
- **Трение** при попытке аристократа уйти из рук инквизиции.
- Обычные дела — каждый в своей зоне.

**Три храма Трикастеллы:**
- Гильдии Торговцев (большой).
- Гильдии Каменщиков (старый; настоятель — старший жрец).
- Гильдии Ростовщиков (богатый).
- Странники Матери могут быть привязаны к конкретному храму или к высшей структуре.

**Дом Альдобранди:**
- **Никаких отношений** — отдельная история.
- Пошлины на переправах — их право и обязанность.

**Материн Голос (Монтевельо):**
- Высшая инстанция.
- Может прислать запрос, вызвать, отменить решение.

## §6. ТРИКАСТЕЛЛА — РАБОЧАЯ КАРТА

**Центр.** Крупный торговый город на юго-восточном выходе из долины Тиччи. 25 км от Академии.

**Кварталы** — канона нет, свобода творчества.

**Ключевые объекты:**
- **трибунал** — у городской стены, с тайным ходом;
- **три храма** — Гильдии Торговцев (большой), Каменщиков (старый), Ростовщиков (богатый);
- **магистрат** — где сидит Бенедетто Корси (`open:`);
- **торг** — где рынок, где считают пошлины (`open:`);
- **переправа через Тиччу** — мост в сторону долины, пошлины Альдобранди.

**Ворота и дороги** — `open:` список.

**«Мокрый» квартал** — `open:` существует ли.

**Слобода язычников** — возможна, отложено на сюжет.

## §7. ДОРОГИ И СВЯЗЬ (сжато)

**Ось (юг → север):** Трикастелла → Бьесса → Кампо → Академия → перевал Горла.

**Переправа через Тиччу:** мост перед Академией. Пошлины — Альдобранди. Трибунал **не платит** (пропуск).

**Транспорт трибунала:** лошади, повозки, кареты — по сезону.

**Связь:**
- гонец с письмом;
- голуби;
- регулярные кареты;
- шпионы.

**Разбойники:** есть. Ущелье Горла — возможное пристанище одной из банд. Трибунал имеет **тайные связи через агентов**, не со всеми.

**Проверки на дорогах:** светская стража. Трибунал — как спецоперация для конкретной цели.

См. `04_dorogi_i_svyazi` для полного.

## §8. ЯЗЫКИ ТРИБУНАЛА

- **Официально — Высокий.** Документы, приговоры, контракты, ритуалы.
- **В быту — Долинный.** Допросы крестьян, улица, торговля.
- **Крестьяне Высокого не знают.**
- **Рабы не имеют права знать Высокий.**
- **Горцы** — ни Высокого, ни Долинного. Перевод — по необходимости.

См. `mir/kultura/mir_yazyki` для полного.

## §9. ИНКВИЗИТОР (карточка-шаблон)

> Карточка **протагониста**. В режиме РЕЖИССЁРА система может прописывать его действия. В режиме ПРОТАГОНИСТА — только среда, NPC, реакции. **Игрок ведёт Инквизитора сам.**

```json
{
  "name": "Инквизитор",
  "role": "старший инквизитор трибунала",
  "age": 0,
  "gender": "",
  "origin": "",
  "appearance": "",
  "voice": "",
  "habits": "",
  "personality": {
    "type": "",
    "traits": []
  },
  "skills": [
    "наблюдательность",
    "допрос",
    "торг",
    "запугивание",
    "знание улик",
    "психология",
    "право (Высокий язык)"
  ],
  "inventory": [
    "золотая пряжка трибунала (лезвие ножа, зажатое в кулак)",
    "печать трибунала",
    "пропускные документы"
  ],
  "health": "",
  "relations": {},
  "knows": [],
  "conditions": [],
  "notes": "Шаблон. Автор заполняет по мере сюжета: имя, возраст, внешность, характер."
}
```

**Что в карточке:**
- **Имя, возраст, внешность, характер** — заполняет автор.
- **Навыки** — фиксированы (совпадают с `rules.md` Блок 5).
- **Инвентарь** — минимум (пряжка, печать, пропуска).
- **Знает** — список фактов, которые Инквизитор знает.
