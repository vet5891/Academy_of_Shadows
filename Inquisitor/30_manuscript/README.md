> Здесь хранится **финальный** текст — после редакторской вычитки.
> Отсюда автор забирает главы для публикации (TG/Boosty — вручную).
> Формат: markdown. ASCII-имена.

---

## Структура

```
30_manuscript/
├── README.md                    (этот файл)
├── book_01/
│   ├── 00_meta.md               мета книги (название, аннотация, список глав)
│   ├── ch_001.md                глава 1 (финал)
│   ├── ch_002.md                глава 2
│   └── …
├── book_02/
│   └── …
└── …
```

## Правила

1. **Одна книга = одна папка** `book_NN`.
2. **Одна глава = один файл** `ch_NNN.md`.
3. **Глава равна серии.** Длина не ограничена.
4. **Метаданные** (`00_meta.md`) — автор заполняет вручную (название, аннотация, дисклеймер 18+).
5. **Публикация** — ручная работа автора. Из этой папки текст копируется в TG/Boosty.
