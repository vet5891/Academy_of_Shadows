# 40_characters — досье персонажей

> Здесь хранятся **развёрнутые** карточки значимых NPC.
> В `inquisitor_state.md` → `cards` — **краткие** карточки для сцен.
> Здесь — **полные досье**: биография, мотивации, тайны, связи, голос, внешность.
> Формат: markdown. ASCII-имена.

---

## Структура

```
40_characters/
├── README.md                    (этот файл)
├── inquisitor.md                Инквизитор (протагонист)
├── secretary.md                 секретарь (когда появится)
├── judges.md                    судьи (когда появятся)
├── priests.md                   жрецы (когда появятся)
├── aristocrats.md               аристократы (когда появятся)
└── …
```

## Правила

1. **Один персонаж = один файл** (или группа — например, «судьи» одним файлом).
2. **Краткая карточка** в `state` обновляется **автоматически** по дельте.
3. **Полное досье** здесь — обновляется **вручную** автором.
4. **Досье** содержит: происхождение, внешность, голос, привычки, характер, мотивации, тайны, связи, знает, инвентарь, здоровье, условия.
5. **Появление** — при первом значимом появлении NPC в сцене.

## Откуда берётся

Начальные данные — из `lore_local.md` §9, §10 (шаблоны) + накопленное по сюжету.

## Персонажи

Пока **никого**, кроме Инквизитора (шаблон).
Создаются по мере развития сюжета.
